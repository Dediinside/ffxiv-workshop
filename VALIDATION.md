# Проверка 0.1.1

## Автоматические проверки

**269 тестов:** 27 новых (крафт, профили, импорт персонажа и локальный API), 89 сохранённых проверок Leve Planner, 87 Market Scout и 66 Рай перекупа. Проверены общий спрос, целые стаки, налоги, EXP/allowances, перенос остатков, уровни и HQ, отсутствие цен, ошибки сети, дедупликация, отмена и сохранение настроек.

Новый движок проверен на примере пользователя: 2 стали и ручка стоят 30 готовыми, доступная цепочка сырья — 12; при недоступном Carpenter ручка покупается. Проверяются более дешёвая покупка вместо изготовления, общие ингредиенты до округления, выход рецепта, недоступные книги/уровни, крафт готового leve-предмета другой доступной профессией, циклы, лимит поиска, HQ из NQ-сырья и дополнительные расходы всех крафтов. Еда/расходники начисляются один раз на этап изготовления и не начисляются заново при использовании готовых остатков.

Контракт Universalis дополнительно проверяет отсутствие параметра ограничения listings (0 означает пустой список) и отсутствие старого кэша при сбое цен.

Локальный API проверен на отказ без ключа сессии, с чужим Origin/Host, на запрет чтения произвольного файла, отсутствие токена Telegram в ответе, загрузку каталогов и выполнение DEMO через HTTP. Импорт проверяет время снимка, уровни/EXP и сохранение ручных HQ/книг. Периодический мониторинг отменяется без второго цикла.

## Интерфейс

Проверен в локальном браузере: основные разделы, сохранение профиля, расчёт следующего рубежа, маршрут 1 → 50, принудительный крафт 1 → 10, получение фактически выбранного списка изготовления, спрос производства/сбора, фильтры качества/прибыли, сортировка и горячий DEMO с остановкой. Демонстрационные цены явно помечены и не являются рекомендациями. Реальные Telegram-сообщения не отправлялись.

## Живая сеть

Одна партия Steel Ingot на Light: 2 реальных HTTP-запроса, 0,85 секунды в этом наблюдении, 3 покупных базовых материала, известная стоимость всей закупки 1 874 gil с налогом и целыми стаками. Ошибок API не было. Это проверка потока цен и расчёта, а не фиксированная выгодная сделка. Результат зависит от снимка, размеров стаков и доступных рецептов; искусственные цены в живом тесте не подставлялись.

## Мост Dalamud

WorkshopBridge собран .NET SDK 10.0.401 против установленного Dalamud 15.0.3.6, сборка Release: 0 ошибок, 0 предупреждений. DLL/manifest находятся в `bridge/release`. Загрузка внутри игрового клиента не выполнялась; требуется отдельная проверка пользователем после установки dev-плагина. Не проверяются автоматически книги, экипировка, allowances, gil и инвентарь. Игровой клиент не автоматизируется.

## Практические пределы

Поиск цепочек ограничен 4 000 состояниями и не смешивает покупку части одного материала с крафтом остатка; предупреждение о лимите сохраняется. Маршрут поэтапный, а не глобальный оптимум. Рыночные данные Universalis собираются игроками и могут запаздывать. Успешное получение HTTP не подтверждает наличие предмета в игре; перед покупкой/продажей нужна проверка. При разрыве WebSocket часть событий может отсутствовать.

Старые проекты сохраняются отдельно; токен и история старого приложения не переносятся автоматически в публичный архив.

В 0.1.1 проверен сохраняемый предел давности последней продажи: продажа 36 часов назад исключается при 24 часах, допускается при 48/72; предел выше 168 отвергается.
